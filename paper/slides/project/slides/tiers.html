Two-tier design

Heavy work only when traffic is abnormal

Tier 1 · EWMA monitor

  • z-score of flows per window, α = 0.1
  • ELEVATED after 3 windows with z > 3
  • NORMAL after 5 windows with z < 2
  • Baseline frozen while ELEVATED

Tier 2 · detector

  • NORMAL: LightGBM on a 10% sample
  • ELEVATED: every flow, LightGBM and Isolation Forest
  • Flag: attack class with p ≥ 0.5, or IForest past its threshold

Exit rule changed from z < 1 for 10 windows: in 200 simulated demo runs it returned to NORMAL before the end in 38% of runs, against 100% for z < 2 for 5.

FlowLens · Review 2 · 06

Tier 1 is deliberately cheap: one number per window. The baseline only learns from calm windows, so an attack never becomes the new normal. Tier 2 is where the models run. The Isolation Forest is trained on benign traffic only, so it can flag attacks LightGBM has never seen. Mention the exit-rule change and the simulation behind it.
