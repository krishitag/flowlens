Our claim

Per-flow explanations are cheap enough for live traffic, given two design choices

01

TreeSHAP on tree models

Exact Shapley values for tree ensembles in polynomial time. Kernel SHAP instead re-runs the model on many perturbed samples for every flow.

02

A two-tier design

A cheap monitor watches traffic volume. Full scoring and explanation run on every flow only while traffic is abnormal.

This is the thesis. We prove it with measurements: TreeSHAP vs Kernel SHAP latency on the same model and flows, and pipeline latency under load.
